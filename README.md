# DSH 取景器 (DshShot)

一键截图 → 自动调 AI 出答案，答案显示在屏幕右侧的悬浮小窗里。

## 下载与安装

不需要安装程序、不需要编译，解压即用：

1. 在 GitHub 页面点 **Code → Download ZIP**（或 `git clone`）
2. 解压到**任意目录**（路径里有空格、中文都可以）
3. 双击 **`install.cmd`** —— 它会在当前目录生成 `DSH 取景器.lnk` 并启动程序

之后每天用就双击那个 `DSH 取景器.lnk`（带图标、不闪黑框）。换目录或换机器，重新跑一次 `install.cmd` 即可。

> 仓库里**不含**快捷方式文件，因为它内部存的是绝对路径；`install.cmd` 会按当前所在目录现算一份。
> 想放到桌面：`install.cmd -Desktop`。

### 下载后被拦住了？（智能应用控制 / SmartScreen）

从浏览器下载的压缩包会被打上「来自 Internet」标记（Zone.Identifier），解压出来的 `.cmd` / `.vbs` 会继承它，Windows 的**智能应用控制**于是提示「具有危险文件扩展名的应用」并阻止运行。

按顺序试，一般第 1 步就够：

1. **删掉已解压的目录**，回到 ZIP 本身：右键 → 属性 → 底部勾选「**解除锁定**」→ 确定 → 重新解压。
2. 已经解压了也行：进目录全选 → 右键 → 属性 → 勾选「解除锁定」。
   或者用 PowerShell 一条命令（路径换成你的解压目录）：
   ```powershell
   Get-ChildItem "$env:USERPROFILE\Downloads\Viewfinder-main" -Recurse | Unblock-File
   ```
3. 仍被拦：「Windows 安全中心」→ 应用和浏览器控制 → 保护历史记录 → 找到这条 →「允许在设备上运行」。
4. 想立刻用、不想折腾解封：打开 PowerShell，直接跑启动脚本（绕过被拦的 .cmd/.vbs）：
   ```powershell
   cd "你的解压目录"
   powershell -NoProfile -STA -ExecutionPolicy Bypass -File .\launch.ps1
   ```
5. 最后手段：关闭智能应用控制（设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制）。注意**关闭后除非重装系统否则无法再开启**，不建议为了这个工具这么做。

确认成功的标志：双击 `install.cmd` 后，目录里出现 `DSH 取景器.lnk`，并弹出设置窗口。

## 启动

- 双击 **`DSH 取景器.lnk`**（推荐，带图标，**不会闪命令行窗口**）
- 或双击 `DshShot.cmd`（等价，但这个文件自身是命令行程序，双击会闪一下黑框）

原理：快捷方式指向 `wscript.exe` + 同目录的 `DshShot.vbs`，由它用隐藏窗口方式拉起 PowerShell，所以全程看不到控制台。所有路径都由脚本自己所在位置推导，没有任何写死的盘符。

启动后**直接弹出设置窗口**（接口 / 自动作答 / 其他三个分页）。

- 关掉窗口不会退出程序，它继续留在右下角托盘里
- 程序已经在跑时再次双击，会**把已有的窗口叫回来**，不会开出第二个
- 勾了「开机自动启动」的话，开机那次是静默的（只留托盘，不弹窗）
- 右键托盘图标可以再打开设置、换热键、看用量统计

## 关于密钥

API Key **只存在本机** `%APPDATA%\DshShot\config.ini`，用 Windows DPAPI 加密，仅当前用户可解。

- 设置窗口里**只显示掩码**（sk-****abcd），点进输入框才会清空换成密码框；点「清除」可删掉已存的 Key
- 仓库里没有任何配置文件：`.gitignore` 已排除 `config.ini` / `*.ini` / `*.key` / `*.env`
- 下载别人的包也不含密钥，第一次运行要在设置里自己填
- 换机器不会带过去，需要重新填一次
- 想彻底清除：删掉 `%APPDATA%\DshShot` 整个目录

## 热键

任何程序里都能按：

| 热键 | 动作 |
| --- | --- |
| `Ctrl+Alt+S` | 截当前窗口 |
| `Ctrl+Alt+A` | 拖选一块区域（`Esc` 取消） |
| `Ctrl+Alt+D` | 只截光标所在的那块屏（双屏不会拼在一起） |

> 这两个自动作答热键可以改：右键托盘 →「热键设置…」，点进输入框直接按组合键即可——两键（`Ctrl+X`）、三键、单个 `F2` 都支持，`Del` 清除，保存后立即生效。

> 想要所有屏幕拼成一张：右键托盘图标 →「所有屏幕（拼接）」

## 截完会怎样

1. 截图存到 `%USERPROFILE%\Pictures\DSH-Shots`（可在设置里改）
2. 文件路径自动复制到剪贴板
3. 右侧弹出解析窗：先显示「识别中…」，再出答案
   - 下面输入框可以追问，追问沿用这张图
   - 「复制」按钮复制整段答案；拖标题栏可挪位置；`Esc` 关闭

## 图片处理（只裁空白，不压缩）

发给模型之前，程序只在本地把大片留白裁掉，**不做缩放、不转 JPEG**——原分辨率直接以 PNG 送出，避免压缩把小字糊掉：

- 判据用**局部梯度**，纯色空白几乎为 0，深浅主题都适用
- 通栏分隔线、细长工具栏/任务栏会被单独处理，不会把边界撑满
- 只裁掉四周空白和贴着画面顶/底的细条，**中间内容一律不动**
- 只影响发给模型的那张图，磁盘上保存的仍是完整截图

实测 1600×1000 的答题页 → 585×471（原面积 **17%**），token 也随之降到 1/6 左右。

> 托盘菜单里的「自动裁掉留白（省 token）」可以关掉。
> 想恢复压缩（省流量、省钱）：设置 →「送原图（不缩放、不转 JPEG）」取消勾选，之后才按 `MaxEdge`（默认 1024）/ `JpegQuality`（默认 80）缩放。

## 回答风格（提示词）

同一设置窗口最下面的「回答风格」文本框就是发给模型的系统提示词。默认已经是「只给答案、不解释」：

```text
你是答题助手。看到题目就直接给答案，不要任何分析、推理、解释或知识点说明。
格式要求：
1. 单选题、多选题：只写题号和选项字母，字母后面跟选项内容，例如「3. C 國」；
   多选题字母连写，例如「5. ABD」；
2. 判断题：只写「对」或「错」；
3. 填空题：只写要填进去的内容，多个空用「；」隔开；
4. 计算题、编程题：只给最终结果或最终代码，不给推导过程；
5. 图里有多道题时，按题号一行一道，不要写多余的话；
6. 看不清或图里没有题目时，只回「看不清」。
不要寒暄，不要复述题干，不要加"答案：""解析："之类的标签，直接输出结果。
```

想恢复成讲思路的模式，把这段改成「给出答案并用几句话说明依据」即可，点「恢复默认」会回到上面这段。

## 自动作答（Ctrl+Alt+Q 预览 / Ctrl+Alt+X 自动点击）

> **状态：待优化。** 日常用建议先用 `Q` 预览确认，别直接挂 `X` 无人值守。
>
> 已知问题：① 页面极密或字号很小时偶发漏题；② 多选/选项相似度极高时仍可能读错；③ 页面停在滚动中间、题目被切一半时不会作答。
>
> 下一步计划：整页图像增强、双模型交叉验证、题块级切分、半自动（拿不准的题标红等人确认）。

先按 `Q` 看框（只画框不点），确认位置对了再按 `X` 真点。运行中按任意一个都是停止。

开启时把**当前前台窗口**（或你最近用过的那个窗口）当目标，之后循环：

> 等你停手 2 秒 → 抓屏 → 上下分两半识别 → 逐题裁剪复核 → 吸准选项位置 → 点击

上一轮什么都没点（没题、都答过了、复检没过）时，会歇 10 秒再试，避免空转烧 token；你一操作就立刻恢复。

托盘菜单 →「自动作答」里可以切：

| 项 | 说明 |
| --- | --- |
| 关闭 / 预览 / 自动点击 | **先用预览**：只在屏幕上画框，不点，确认对得上再开自动 |
| 目标窗口 | 点一下把当前前台窗口设为目标 |
| 抓取间隔 | 2 / 3 / 5 / 8 秒。这只是轮询节奏，真正的闸门是「停手 2 秒」 |
| 点击方式 | 前台（真的移动光标，兼容性最好）/ 后台（给窗口投消息，不动光标） |
| 点击前复检选项文字 | 把要点的框裁出来 OCR 一遍，和选项原文比对，不一致就不点 |
| 填空题自动粘贴 | 默认关；开了会点中填空框再粘贴答案 |

### 观察窗

开启自动作答时会自动弹出一个状态窗（右上角），实时显示：

- **当前阶段**：等输入停下 / 下一轮 Ns 后 / 识别中 / 答案不全重试中 / 正在复检第几题 / 本轮完成
- **目标窗口**和模式
- **本轮 N 题 · 已点 N 次 · 调用 N 次 · 累计 token · 累计费用**
- **缩略图**：最近一次抓到的画面，框出准备点的地方
- **滚动日志**：每次识别、点击、跳过的原因

窗口可以拖着走，点右上角 `✕` 直接停止自动作答。它自身会在截图里被涂白，不会被当成题目。

### 识别不全 / 框偏了怎么办

自动作答单独用一套图片参数（跟手动截图的 `MaxEdge` / `JpegQuality` 互不影响）：

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `AutoMaxEdge` | 1600 | 送模型的最长边。识别不全就调到 2048（token 约翻倍） |
| `AutoQuality` | 88 | JPEG 质量。字细、背景花可以调到 92 |
| `AutoSplitScan` | 1 | 上下分两半各识别一次再合并，专门治「最后一题漏掉」；设 0 关掉可省一半调用 |
| `AutoIdleMs` | 2000 | 键盘/鼠标要静止这么久才开始识别；打字、点鼠标、移动、滚轮都算「还在操作」 |
| `AutoDoubleCheck` | 1 | 逐题裁剪放大再问一次，两次答案不一致就不点（每轮多 N 次调用） |
| `AutoThinkTie` | 1 | 两次答案冲突时，用思考模式裁决第三次；跟哪一次一致就采用哪一次，仍不一致才跳过 |
| `AutoWebSearch` | 1 | 裁决还定不下来时，联网搜一次再让模型结合资料作答（每次约 ¥0.005 + 2 次调用） |
| `NoCompress` | 1 | 不缩放、不转 JPEG，原分辨率 PNG 送模型；设 0 才按 `AutoMaxEdge`/`AutoQuality` 压缩 |

都在 `%APPDATA%\DshShot\config.ini` 里，改完重启程序。

另外几条经验：

- 浏览器缩放保持 **100%**，缩到 80% 以下小字会糊
- 页面别停在滚动中间，题目被切一半时模型会跳过那题
- 有弹窗、悬浮广告挡住选项时，识别和点击都会受影响
- 每点一下之前都会用 OCR 把框「吸」到选项文字上（上下最大试探 ±18% 图高），所以轻微偏框能自动纠正；差得太多就会放弃点击并提示，不会乱点

### 准确率是怎么保的（七道闸）

1. **不压缩原图**：只裁掉四周空白，剩下原分辨率以 PNG 送出（设置里「送原图」开关），彻底避开缩放/JPEG 把小字糊掉。
2. **上下分两半扫**：一屏拆成上下两半（重叠 16%）各识别一次，再按题号合并去重，底部那道题不再漏。
3. **逐题复核**：把每道题单独裁出来，2 倍放大 + 提对比度，只问这一题，得到第二个答案；并且要求它连选项原文一起抄回来。
4. **两次答案比对**：整页答案 vs 单题答案，字母要一致，它抄回来的选项原文也要和那一项对得上；不一致就不点。单选比字母、多选比字母集合（顺序无关）、判断比语义、填空比文字包含。
5. **冲突才用思考模式**：两次不一致时，再用思考模式裁决第三次，跟哪一次一致就采信哪一次。实测简单题开思考要 36 秒、关思考 1.7 秒且答案相同，所以只在冲突时付这个钱。
6. **还定不下来就联网**：让模型先给一个搜索词，调 DeepSeek Search 取回 4 条资料，再让它结合资料答一遍；只有与已知两/三个答案之一对上才点，否则放弃。搜索 ¥5/千次，只在这类冲突题上触发。
7. **点前 OCR 吸框 + 严格匹配**：把要点的区域裁出来 OCR，和选项原文做**完全包含**比对（「十一届三中全会」和「十一届六中全会」不会被判成同一个）；对不上就在上下 ±18% 范围内找文字真正所在的位置，仍找不到就放弃。点之前还会再确认画面没变、同一题 90 秒内不重复点。

### 两个必须知道的前提

- **目标窗口必须露在最上面**。读屏用的是 `CopyFromScreen`（和 BetterGI 的 BitBlt 后端同一类做法），被别的窗口盖住时拍到的是盖住它的那个窗口。要截被遮挡的窗口得换成 WGC，那是另一套东西。
- 自动点击默认走「前台」通道，会真的移动你的鼠标；游戏/网页如果启用了防机器人，这种输入可能被识别。

## 为什么是 `.cmd + .dll` 而不是 `.exe`

这台机器开了 Windows 的「智能应用控制」(Smart App Control)，它会拦截所有没有签名、没有信誉记录的新 exe（事件日志里能看到 Code Integrity 拦截记录）。所以新版做成了 DLL + PowerShell 宿主启动，不依赖 exe，也不会被拦。

如果哪天关掉了 Smart App Control，可以再编译成单文件 exe。
